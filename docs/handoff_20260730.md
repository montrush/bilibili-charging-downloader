## 1. 本次完成内容

### 1.1 前端 (React + TypeScript + Ant Design + Vite)
- 登录页: 扫码登录B站, 二维码实时生成+轮询状态
- 下载页:
  - 链接输入框 + 解析按钮
  - **多类型链接识别展示**: 视频/合集/专栏文章/图片动态
  - 合集自动展开为复选框表格, 默认全选
  - 下载路径输入 + 下载按钮
  - 实时进度条 + 当前任务 + 失败列表
- **手机端适配**: 使用 `Grid.useBreakpoint()` 检测移动端, 小屏幕下:
  - 页面 padding 从 24px 降到 12px
  - 表格横向滚动
  - 下载路径与按钮垂直堆叠
  - 按钮块级显示
  - 字体/图片尺寸自适应
- UI: 皮肤切换器 + 动态背景 + Logo

### 1.2 后端 (FastAPI + Python)
- 链接解析服务 (`server/services/bili_dl.py`) 重写, 支持:
  - **短连接**: `b23.tv/xxx` (自动 302 解析)
  - **微信分享链接**: 通常为 `b23.tv/xxx` 域名, 同样自动解析
  - **PC端HTTP**: `www.bilibili.com/video/BVxxx`, `/avxxx`, 含参数链接
  - **合集链接**:
    - `space.bilibili.com/{mid}/channel/collectiondetail?sid={sid}`
    - `video/BVxxx/?...&sid={sid}` (无效 sid 自动降级为单视频)
    - UGC 合集 (视频详情页 `ugc_season` 字段)
  - **专栏文章**: `www.bilibili.com/read/cv{id}`
  - **图片/动态**: `t.bilibili.com/{id}`, `h.bilibili.com/{id}`, `opus/{id}`
- 解析 API 返回统一格式, 含 `link_type` + `message` + 类型专属字段
- 登录服务: 直接调B站扫码登录 API, 从 `Set-Cookie` 提取 SESSDATA (解决 BBDown 1.6.3 login bug)
- 下载服务: 后台线程管理 + 进度状态

### 1.3 打包与部署
- `Dockerfile`: Linux 镜像, 内置 BBDown + ffmpeg
- `docker-compose.yml`: 一键启动
- `unraid/bilibili-charging-downloader.xml`: Unraid Community Applications 模板
- `.github/workflows/docker.yml`: CI 自动构建 linux/amd64 + linux/arm64 镜像并推送到 GHCR
- `run_windows.bat`: Windows 原生运行入口
- `README.md`: 中文使用说明 + 常见问题
